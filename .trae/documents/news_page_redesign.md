# 学院新闻页面 UI 重新设计计划

## 1. 需求与目标
- **重构页面排版**：将《学院新闻》页面的新闻展示方式重构为“经典纵向列表”布局，一页展示 5 篇文章。
- **提升设计感**：解决当前页面“大面积纯白、缺乏设计感”的问题，通过引入背景层次、阴影、微交互以及装饰性元素，提升整体视觉体验。

## 2. 当前状态分析
- 目前 `college-news.html` 的主体部分直接使用了纯白背景，新闻卡片虽然有投影，但整体仍显得扁平和单调。
- 现有页面仅展示了 3 篇文章，且图文排版不统一（有的有图，有的无图），导致列表缺乏一致的视觉节奏。

## 3. 具体修改方案

**修改文件**：`college-news.html`

### 3.1 增加背景层次与环境装饰
- **背景优化**：将主内容区的背景从纯白 (`bg-white`) 改为带有一点冷色调的浅灰蓝 (`bg-slate-50` 或底层铺设大面积浅色渐变)，让新闻卡片（保持白色或毛玻璃效果）能够“浮”出来，产生前后空间感。
- **装饰元素**：在页面背景中加入一些不规则的浅色光晕（Blur）或网格点阵图案，打破单调感，增加科技与学术氛围。

### 3.2 设计“经典纵向列表”
- **统一的图文结构**：5 篇文章统一采用“左侧图片 + 右侧内容”的卡片式横向排版，保持视觉的整齐与统一。
- **引入时间轴/日历元素**：在左侧或者图片上方引入日历样式的日期块（如大字号的“日”+ 小字号的“年月”），增强新闻的时效性和排版细节。
- **卡片样式优化**：
  - **无边框+软阴影**：卡片使用更柔和的弥散阴影（Soft Shadow），去掉生硬的细边框。
  - **微交互增强**：保留“鼠标划入变为白手套”，增加鼠标悬浮时图片轻微放大（Scale）、卡片略微上浮，以及标题颜色平滑过渡的动效。
  - **标签与元数据**：增加高亮的新闻分类标签（如“重点新闻”、“学院动态”），丰富文字的排版层级。

### 3.3 内容填充
- 将列表项从现有的 3 个扩充到 5 个。
- 为新增的 2 篇文章补充占位图片、标题和摘要文本，确保效果饱满。

## 4. 验证步骤
- 保存文件后，在本地服务器 (`http://localhost:3000/college-news.html`) 预览页面。
- 检查 5 篇文章的列表是否排列整齐，图片和文字比例是否协调。
- 体验悬停交互，确认页面的空间感和设计感得到明显改善，不再显得过度“白茫茫”。
