# 导航栏样式微调计划

## 1. 问题分析
根据用户的反馈，目前导航栏存在以下两个问题：
1. **“新闻通知”下拉菜单超出屏幕**：由于原先的右侧内容区（`col-span-7`）采用单列排列（`flex-col`），左侧信息区（`col-span-5`）保持不变。但最外层弹窗设置了 `w-[60vw] max-w-[800px]` 和 `-left-[300px]`，在一些较小的屏幕上，`-left-[300px]` 的固定偏移量不足以将整个下拉框拉回屏幕内，导致右侧仍然会超出。
2. **图标和文字大小不一致**：“非学历教育”和“新闻通知”的二级栏目样式与“学院概况”不统一。
   - “学院概况”中的图标是 `w-6 h-6`，容器是 `w-12 h-12`，标题是 `text-base`。
   - 而“非学历教育”和“新闻通知”中的图标是 `w-8 h-8`，容器是 `w-14 h-14`，标题是 `text-lg`。

## 2. 修改方案

### 2.1 修复“新闻通知”超出屏幕的问题
- **方案**：调整“新闻通知”下拉菜单最外层的定位和宽度类名。将其与导航项右对齐，而不是使用固定的负 `left` 值。
- **具体修改**：将 `<div class="mega-menu absolute top-full right-0 xl:right-auto xl:-left-[300px] w-[60vw] max-w-[800px] ...">` 修改为 `<div class="mega-menu absolute top-full right-0 w-[60vw] max-w-[800px] ...">`。移除 `xl:-left-[300px]` 和 `xl:right-auto`，确保它始终向右侧对齐，或者设置为 `right-0` 并限制宽度。为了更安全，可以直接使用 `right-0`（在所有屏幕尺寸下都靠右对齐）。

### 2.2 统一二级栏目的图标和文字大小
- **方案**：将“非学历教育”和“新闻通知”中的二级栏目样式，统一改为与“学院概况”相同的样式。
- **具体修改（非学历教育和新闻通知）**：
  - 容器尺寸：`w-14 h-14` -> `w-12 h-12`
  - 图标尺寸：`w-8 h-8` -> `w-6 h-6`
  - 标题文字大小：`text-lg` -> `text-base`
  - 间距（可选）：`gap-6` -> `gap-5`（与学院概况保持一致）
  - 描述文字大小保持原样或统一为 `text-[11px]`。

## 3. 涉及的文件
需在以下四个文件中同步修改：
- `index.html`
- `party-building.html`
- `college-news.html`
- `about.html`

## 4. 验证步骤
1. 检查“新闻通知”下拉菜单是否不再超出屏幕边界。
2. 检查三个下拉菜单中的图标大小和标题文字大小是否完全一致。
